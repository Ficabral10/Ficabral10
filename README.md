#### [⚽ Premier League Match Predictor](https://github.com/Ficabral10/Premier-League-Predictions)
Compares six ML models (Elo, logistic regression, random forest, XGBoost, a Poisson goals model and an ensemble) on 3,800 unseen matches with a walk-forward backtest. **54.4% accuracy vs a 44.6% baseline**, well-calibrated probabilities, and a Streamlit app that predicts any fixture's result and scoreline.
